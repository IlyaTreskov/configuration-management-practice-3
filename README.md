# Конфигурационное управление — практическая работа №3

**Вариант 34.** Ассемблер и интерпретатор учебной виртуальной машины.

В программе используется один регистр-аккумулятор. Синтаксис исходного
файла напоминает традиционный ассемблер: `МНЕМОНИКА ЧИСЛО`. Допускаются
комментарии после `#` или `;`. Команды `LOAD`, `READ`, `STORE`, `OR`.

## Этап 1 — перевод в промежуточное представление

```bash
python -m src.assembler examples/spec_tests.asm build/spec_tests.bin --test
python -m unittest discover -s tests -v
```

В тестовом режиме показываются поля A и B. Двоичный вывод добавляется
в следующем этапе.
